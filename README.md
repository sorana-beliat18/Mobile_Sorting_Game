## 📌 Project Overview
This repository contains the source code for my Bachelor's Degree Final Project. "Cozy Potion Sort" is a 2D mobile puzzle game developed entirely using the **Unity Engine** and **C#**. The main focus of this project was to combine creative game design with clean software architecture and custom mathematical algorithms.

## 🚀 Key Features & Technical Highlights
* **Reverse Shuffle Algorithm:** Implemented a custom mathematical algorithm that dynamically generates levels starting from a victory state, guaranteeing 100% mathematically solvable puzzles.
* **GameManager Architecture:** Structured the application using a central GameManager system to efficiently coordinate game states, UI components, and user inputs.
* **Mystery Bottles Mechanic:** Added a custom difficulty layer by hiding certain layers of liquid, requiring strategic planning and complex multi-dimensional array management.
* **Core Stack Logic:** Managed complex game mechanics (liquid pouring, undo systems, color tracking) by developing custom C# functions utilizing Stack data structures.

## 🛠️ Technologies Used
* **Game Engine:** Unity
* **Programming Language:** C#
* **Design & Prototyping:** Figma / Canva
* **Version Control:** Git / GitHub

## 🎮 How to Play
The objective is simple but challenging: sort the colored potions in the tubes until each tube contains only one specific color. Strategize your moves and watch out for the mystery layers that hide the true colors beneath!
