
# Water Sort Game - Bachelor's Degree Project

## Project Overview
This repository contains my Bachelor's Degree Final Project. It is a mobile puzzle game inspired by the "Water Sort" mechanics, developed using **Unity Engine** and **C#**.

## Key Features
* **Core Logic:** Implemented using Stack data structures for liquid pouring mechanics.
* **Responsive UI:** Designed to work on both smartphones and tablets (Scale with Screen Size).
* **Game Mechanics:** Level management, color sorting algorithms, and undo system.

## Technologies Used
* **Engine:** Unity 2022.x (sau versiunea ta)
* **Language:** C#
* **Design:** Figma / Canva

## How to Play
Sort the colored water in the tubes until all colors are in the same tube.
